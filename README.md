# Sepsis Prediction Using Machine Learning

## Project Overview
This project uses machine learning to identify sepsis-related patterns in clinical data. It uses the PhysioNet 2019 Challenge dataset, a LightGBM model, and a Streamlit application.

## Objectives
- Explore clinical data and handle missing values.
- Train a LightGBM classification model.
- Address class imbalance.
- Evaluate performance using precision, recall, F1-score, ROC-AUC, and PR-AUC.
- Create an interactive Streamlit demonstration.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- LightGBM
- Jupyter Notebook
- Streamlit

## Project Workflow
1. Data loading and exploration
2. Data preprocessing
3. Patient-wise data splitting
4. Model training
5. Model evaluation and threshold selection
6. Streamlit application development

## Dataset
PhysioNet 2019 Challenge:
https://physionet.org/content/challenge-2019/

The dataset is not included in this repository. Obtain it from the official source and follow its access and usage requirements.

## Evaluation
The model is evaluated using multiple classification metrics. Refer to the notebook for the actual results.

## Limitations
This project is an academic demonstration, not a clinically validated diagnostic system. It must not be used to make medical decisions.
